# Setting Up a KPI

A KPI (Key Performance Indicator) is any measurable value that reflects how your business is performing against a specific goal. In Sortment, a KPI is a tracked metric that refreshes on a schedule so you always have an up-to-date view of the number that matters, without building a dashboard or writing a query every time you need to check it.

KPIs are flexible by design. Some examples of what teams track as KPIs:

- Number of paid users
- Conversion rate in an onboarding funnel
- Day 30 churn rate

You can define a KPI using set logic on the Sortment dashboard (no code required) or with a raw SQL query for full control. Both approaches produce a KPI that shows up the same way — with a current value, a trend chart, and a configurable refresh schedule.
