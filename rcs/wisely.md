# Wisely

Before you begin, you will need a Wisely account already set up, with Sender ID and templates configured.

#### 1. Find the provider

Go to Settings → Engagement Setup → Sender Profiles. Select the RCS channel, then click Add integration and choose Wisely as the provider.

#### 2. Configure the integration

In the pop-up, fill in:

* **Custom name**: A name to help you identify the configured account in Sortment's portal.
* **Sender**: In Wisely, go to Channels → RCS → My Agents, and fetch the Agent ID.
* **Access Key**: In Wisely, go to API → Access Accounts. Click the key icon on an existing account to get the Access Key, or click Create New.

#### 3. Complete the integration

Click Save once done, and you are all set.

### Message delivery status

Sortment can track notification delivery status, but Wisely requires a manual update of the Callback Endpoint to receive these reports. To update it:

1. Copy the Callback URL from the integration pop-up in Sortment.
2. Send the Callback URL to your Wisely account manager to add it to your Wisely account.
