# ValueFirst

Before you begin, you will need a ValueFirst account already set up, with Sender ID and templates configured.

#### 1. Find the provider

Go to Settings → Engagement Setup → Sender Profiles. Select the RCS channel, then click Add integration and choose ValueFirst as the provider.

#### 2. Configure the integration

In the pop-up, fill in:

* **Custom name**: A name to help you identify the configured account in Sortment's portal.
* **Username**: The username of your ValueFirst RCS account.
* **Token**: Contact your ValueFirst RCS account manager to get this token.

#### 3. Complete the integration

Click Save once done, and you are all set.

### Message delivery status

Sortment can track notification delivery status, but ValueFirst requires a manual update of the Callback Endpoint to receive these reports. To update it:

1. Copy the Callback URL from the integration pop-up in Sortment.
2. Send the Callback URL to your ValueFirst account manager to add it to your ValueFirst account.
