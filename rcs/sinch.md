# Sinch

Before you begin, make sure you have a Sinch account with RCS enabled.

All required integration details will be provided by the Sinch team upon request. The API credentials used here are different from your Sinch account login credentials.

#### 1. Find the provider

Go to Settings → Engagement Setup → Sender Profiles. Select the RCS channel, then click Add integration and choose Sinch as the provider.

#### 2. Configure the integration

In the pop-up, fill in:

* **Custom name**: A name to help you identify this account within Sortment.
* **Username**: The API username provided by Sinch.
* **Password**: The API password provided by Sinch.
* **App ID**: The application ID shared by Sinch for your RCS setup.
* **Project ID**: The project ID associated with your Sinch account.

#### 3. Update account and run test

You can edit and update your details at any time. Fields that are greyed out can't be modified. Use Run Test to verify the saved configuration is correct.

#### 4. Complete the integration

Click Save once all required fields are filled in. Your Sinch RCS account will now be configured.
