# Gupshup Enterprise

Before you begin, you will need a Gupshup Enterprise account already set up, with Sender ID and templates configured.

#### 1. Find the provider

Go to Settings → Engagement Setup → Sender Profiles. Select the RCS channel, then click Add integration and choose Gupshup Enterprise as the provider.

#### 2. Configure the integration

In the pop-up, fill in:

* **Custom name**: A name to help you identify the configured account in Sortment's portal.
* **UserID**: The Customer ID shown on your Gupshup Enterprise account dashboard when you log in.
* **Password**: The password used to log into the Customer ID entered above.

#### 3. Complete the integration

Click Save once done, and you are all set.

### Message delivery status

Sortment can track notification delivery status, but Gupshup Enterprise requires a manual update of the Callback Endpoint to receive these reports. To update it:

1. Copy the Callback URL from the integration pop-up in Sortment.
2. Send the Callback URL to your Gupshup account manager to add it to your Gupshup account.
