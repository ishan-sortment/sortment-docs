# Tasks

A Task is a recurring instruction you give Sortment to perform a specific piece of work on your workspace, on a schedule you define. Describe the work once and Sortment keeps doing it, surfacing a report each time it runs.

### How to create a Task

1. **Describe the work:** Tell Sortment what you want it to do, in plain language - for example, "audit the campaigns currently running in my workspace every day at 10am and flag anything worth attention."
2. **Answer any clarifying questions:** If the agent needs more detail to run the Task correctly, it will ask. For example, it may ask which metrics to prioritize or which campaigns to include.
3. **Confirm the schedule:**  a specific day, interval, or time of day the Task should run on.
4. **The Task goes live.** Once everything is confirmed, the Task is active and will run automatically on the schedule you set.

**Where to find your Tasks:** Click the chat icon on the home page, then switch to the **Tasks** tab. This is where you can see all your active Tasks and read the reports each run produces.<br>

#### Example

> **You:** "Create a Task that audits the campaigns currently running on my workspace every day and gives me a report on issues, insights, and actionables."
>
> **Sortment:** "What time should I run this audit every day?"
>
> **You:** "9 AM every day."
>
> **Result:** Sortment creates the recurring Task. Every day at 9 AM, it runs the campaign audit and drops the report into your Tasks view

### Interacting with a Task&#x20;

**From an Alert or Insight.** When a Task run produces something worth surfacing, it shows up as an Alert or Insight on your home page. Click into it, then select **Explore** to open an AI chat that already has the context of that Task run loaded in, so you can ask follow-up questions or dig deeper without re-explaining what you're looking at.<br>

**From the Task report directly.** You can also go straight to a specific run's report:

1. Click the chat icon on the home page.
2. Switch to the **Tasks** tab.
3. Select the run you want to see the report for.
