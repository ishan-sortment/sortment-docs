# WebEngage

Sortment connects to WebEngage, letting Sortment AI manage users, campaigns, and analytics via the WebEngage API. This is useful for teams migrating off WebEngage, or running it alongside Sortment for specific channels during a transition.

***

### How to use

1. Click the workspace name in the top right.
2. Go to **Workspace Settings**.
3. Go to **Connectors**.
4. Find **WebEngage** and select **Connect**. This connector uses an API key, so you'll need to generate one from your WebEngage dashboard and enter it during setup.
