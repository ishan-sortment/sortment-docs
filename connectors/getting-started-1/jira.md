# Jira



Sortment connects to Jira, letting Sortment AI create and manage issues, projects, and sprints via the Jira REST API. This is mainly useful for tying engineering and product work to campaign or journey timing.

***

### How to use

1. Click the workspace name in the top right.
2. Go to **Workspace Settings**.
3. Go to **Connectors**.
4. Find **Jira** and select **Connect**. This connector uses an API key, so you'll need to generate one from your Atlassian account settings and enter it during setup.

***

### What can this power

* Timing a campaign or journey launch around a Jira sprint or release by checking status directly from Sortment AI
* Creating a Jira ticket for a follow-up fix when a campaign surfaces a product issue, without switching tools
