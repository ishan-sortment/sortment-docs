# Customer.io



Sortment connects to Customer.io, letting Sortment AI send and manage campaigns, events, and customer data via the Customer.io API. This is useful for teams migrating off Customer.io, or running it alongside Sortment.

***

### How to use

1. Click the workspace name in the top right.
2. Go to **Workspace Settings**.
3. Go to **Connectors**.
4. Find **Customer.io** and select **Connect**. This connector uses an API key, so you'll need to generate one from your Customer.io workspace settings and enter it during setup.

***

### What can this power

* Bringing historical Customer.io campaign and event data into Sortment for a single view of engagement across both tools
* Comparing campaign and event data across Customer.io and Sortment during a migration, so nothing gets lost in the switch
* Data attribute sync from Sortment -> Customer.io.&#x20;
