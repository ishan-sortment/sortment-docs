# GitHub

Sortment connects to GitHub through a hosted MCP server, letting Sortment AI access repositories, issues, and pull requests. This is mainly useful for tying product or engineering context, like a feature rollout or bug fix, to campaign and journey timing.

***

### How to use

1. Click the workspace name in the top right.
2. Go to **Workspace Settings**.
3. Go to **Connectors**.
4. Find **GitHub** and select **Connect**. This connector runs through GitHub's hosted MCP server, so you'll authorize access as prompted.

***

### What can this power

* Timing a campaign or journey launch around a feature release by checking its rollout status directly from Sortment AI
* Surfacing whether a spike in support tickets or churn coincides with a recent deploy or open issue
