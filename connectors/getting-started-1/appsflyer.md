# AppsFlyer

Sortment connects to AppsFlyer through a hosted MCP server, letting Sortment AI pull mobile attribution and campaign analytics data. This brings install and acquisition data into the same view as everything that happens after a customer opens the app.

***

### How to use

1. Click the workspace name in the top right.
2. Go to **Workspace Settings**.
3. Go to **Connectors**.
4. Find **AppsFlyer** and select **Connect**. This connector runs through AppsFlyer's hosted MCP server, so you'll authorize access as prompted.

***

### What can this power

* A full view of the customer journey, from which channel or campaign drove the install through to product activation and lifecycle engagement
* Analysis of which acquisition sources and campaigns lead to the best downstream retention, not just install volume
