# Infronics

Before you begin, you will need an Infronics account already set up, with Sender ID and templates configured.

#### 1. Find the provider

Go to Settings → Engagement Setup → Sender Profiles. Select the SMS channel, then click Add integration and choose Infronics as the provider.

#### 2. Configure the integration

In the pop-up, fill in:

* **Custom name**: A name to help you identify the configured account in Sortment's portal.
* **Username**: The username shown on your Infronics account dashboard when you log in.
* **Password**: The password used to log into the account entered above.
* **Sender**: Enter the Sender ID you want to use.
* **DLT Entity ID**: Enter your DLT registered Entity ID.
* **Route**: Select the route type: Transactional or OTP.

#### 3. Complete the integration

Click Save once done, and you are all set.

### Message delivery status

Infronics provides message delivery status by default, with no additional setup needed.

Once the integration is complete, the delivery status shared by Infronics will show up in the logs. Click on a log entry and check the Delivery tab.
