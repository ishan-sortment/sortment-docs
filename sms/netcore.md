# Netcore

Before you begin, you will need a Netcore account already set up, with Sender ID and templates configured.

#### 1. Find the provider

Go to Settings → Engagement Setup → Sender Profiles. Select the SMS channel, then click Add integration and choose Netcore as the provider.

#### 2. Configure the integration

In the pop-up, fill in:

* **Custom name**: A name to help you identify the configured account in Sortment's portal.
* **Account ID**: The unique identifier representing the channel owned by your enterprise.
* **Username**: The Customer ID shown on your Netcore account dashboard when you log in.
* **Password**: The password used to log into the Customer ID entered above.
* **Sender**: The Sender ID you use to send out messages.

#### 3. Complete the integration

Click Save once done, and you are all set.

### Message delivery status

Netcore provides message delivery status by default, with no additional setup needed.

Once the integration is complete, the delivery status shared by Netcore will show up in the logs. Click on a log entry and check the Delivery tab.
