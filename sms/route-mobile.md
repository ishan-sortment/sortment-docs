# Route Mobile

Before you begin, you will need a Route Mobile account already set up, with Sender ID and templates configured.

#### 1. Find the provider

Go to Settings → Engagement Setup → Sender Profiles. Select the SMS channel, then click Add integration and choose Route Mobile as the provider.

#### 2. Configure the integration

In the pop-up, fill in:

* **Custom name**: A name to help you identify the configured account in Sortment's portal.
* **Username**: The username you use to log into Route Mobile.
* **Password**: The password you use to log into Route Mobile.
* **Sender**: The Sender ID you want to use with this integration.
* **Entity ID**: Your company's DLT Entity ID (India only).

#### 3. Complete the integration

Click Save once done, and you are all set.

### Message delivery status

Route Mobile provides message delivery status by default, with no additional setup needed.

Once the integration is complete, the delivery status shared by Route Mobile will show up in the logs. Click on a log entry and check the Delivery tab.
