# MessageBird

Before you begin, you will need a MessageBird account already set up, with Sender ID and templates configured.

#### 1. Find the provider

Go to Settings → Engagement Setup → Sender Profiles. Select the SMS channel, then click Add integration and choose MessageBird as the provider.

#### 2. Configure the integration

In the pop-up, fill in:

* **Custom name**: A name to help you identify the configured account in Sortment's portal.
* **API Key**: In MessageBird, click Developers in the left navigation, then API Access. Create a new key or use an existing one.
* **Originator**: Enter the Sender ID you want to use.

#### 3. Complete the integration

Click Save once done, and you are all set.

### Message delivery status

MessageBird provides message delivery status by default, with no additional setup needed.

Once the integration is complete, the delivery status shared by MessageBird will show up in the logs. Click on a log entry and check the Delivery tab.
