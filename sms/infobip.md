# Infobip

Before you begin, you will need an Infobip account already set up, with Sender ID and templates configured.

#### 1. Find the provider

Go to Settings → Engagement Setup → Sender Profiles. Select the SMS channel, then click Add integration and choose Infobip as the provider.

#### 2. Configure the integration

In the pop-up, fill in:

* **Custom name**: A name to help you identify the configured account in Sortment's portal.
* **Infobip Base URL**: Found on your Infobip home page, in the format xxxxx.api.infobip.com.
* **API Key**: Log into Infobip, go to Menu → Developer Tools → API Key, and copy an existing key or create a new one.
* **Sender**: Enter the Sender ID you want to use.
* **Entity ID (DLT)**: Enter your DLT registered Entity ID, available on your DLT platform.

#### 3. Complete the integration

Click Save once done, and you are all set.

### Message delivery status

Infobip provides message delivery status by default, with no additional setup needed.

Once the integration is complete, the delivery status shared by Infobip will show up in the logs. Click on a log entry and check the Delivery tab.
