# Ozonetel

Before you begin, you will need an Ozonetel account already set up, with Sender ID and templates configured.

#### 1. Find the provider

Go to Settings → Engagement Setup → Sender Profiles. Select the SMS channel, then click Add integration and choose Ozonetel as the provider.

#### 2. Configure the integration

In the pop-up, fill in:

* **Custom name**: A name to help you identify the configured account in Sortment's portal.
* **API Key**: From your Ozonetel platform, find Power API and click API Keys. Create a new key or use an existing one.
* **Sender**: Enter the Sender ID you want to use.
* **Entity ID**: Enter your DLT registered Entity ID.
* **Type of SMS**: Select the SMS type: Transactional, Promotional, or OTP.

#### 3. Complete the integration

Click Save once done, and you are all set.

### Message delivery status

Ozonetel does not provide message delivery status by default.

Once the integration is complete, the delivery status shared by Ozonetel will show up in the logs. Click on a log entry and check the Delivery tab.
