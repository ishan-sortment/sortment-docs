# Kaleyra.io

Before you begin, you will need a Kaleyra.io account already set up, with Sender ID and templates configured.

#### 1. Find the provider

Go to Settings → Engagement Setup → Sender Profiles. Select the SMS channel, then click Add integration and choose Kaleyra.io as the provider.

#### 2. Configure the integration

In the pop-up, fill in:

* **Custom name**: A name to help you identify the configured account in Sortment's portal.
* **SID (Security Identifier)**: Found on Kaleyra.io under the Developers tab, from a previously created API key or by creating a new one.
* **API Key**: Also found on Kaleyra.io under the Developers tab. Copy an existing key or create a new one.
* **Sender**: Enter the Sender ID you want to use.
* **Type of Route**: Select the route type based on the configuration added in your Kaleyra.io application.

#### 3. Complete the integration

Click Save once done, and you are all set.

### Message delivery status

Kaleyra.io provides message delivery status by default, with no additional setup needed.

Once the integration is complete, the delivery status shared by Kaleyra will show up in the logs. Click on a log entry and check the Delivery tab.
